# NG-CANDIDATE-2026.8 runtime integration

2026.8 inherits the reviewed 2026.7 authoritative Salary, annualization, YTD, relief, prior-employer, binding, decision, and PAYE arithmetic. Runtime dispatch resolves and freezes sources under `NG-CANDIDATE-2026.8`, calculates distinct 2026.8 hashes, and retains `NOT_CERTIFIED`.

No migration is required. Exact-SHA staging deployment is intentionally deferred until the implementation-plus-PostgreSQL checkpoint is independently reviewed.
