## Baseline conclusions

- The dominant reliability risk is that the shared reveal system emits `opacity: 0` in server-rendered HTML and only reveals after a client effect.
- Home, Industries, Careers, About, and Contact use the same reveal/stagger pattern repeatedly, diluting each page’s intended interaction priority.
- Services has meaningful tab and ticker behavior, but coded previews run decorative counter/chart/status sequences simultaneously.
- The main semantics are already sound for the solution tabs and accordions; mobile-menu focus containment and form error/status associations are the largest accessibility gaps.
